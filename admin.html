One last step in Render

The Studio saves your files in GitHub, so Render needs a GitHub key (only once):

  1. Create it at github.com → new fine-grained token: Only select repositories → concierge-pixel/Newsletters, and Contents: Read and write.
  2. In Render, open this Web Service → Environment → Add Environment Variable: key GITHUB_TOKEN, value = the key you copied.
  3. Click Save, rebuild, and deploy. When it says Live, reload this page.
