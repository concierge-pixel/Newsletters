Connect to GitHub (one time only)

  1. Open GitHub → Generate new token (fine-grained).
  2. Token name: Newsletters uploader. Expiration: the longest it allows.
  3. Repository access: Only select repositories → concierge-pixel/Newsletters.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it and paste it below.

The token is saved only in this browser. Your client never sees it.
